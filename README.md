# Weather App 🌦️

This Weather App is a user-friendly platform to check real-time weather conditions for any city worldwide. Designed with simplicity and efficiency, it delivers accurate weather data fetched from a weather API, displayed in an engaging and responsive UI.

## 🌟 Features  
- **Real-Time Weather Updates:** Get up-to-date weather information for any city, including temperature, humidity, and conditions.  
- **Search Functionality:** Effortlessly search for weather data by city name.  
- **Responsive Design:** Optimized for seamless usage across desktops, tablets, and mobile devices.  
- **Engaging UI:** Minimalistic design with dynamic visuals for an enhanced user experience.  

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript, React.js  
- **API Integration:** Weather API for fetching live weather data.  

## 🚀 Getting Started  
Follow these steps to set up the project locally:  

### Prerequisites  
Ensure you have the following installed:  
- [Node.js](https://nodejs.org/)  
- [npm](https://www.npmjs.com/)  

### Installation  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/Rishika-108/Weather-App.git  
   ```  
2. Navigate to the project directory:  
   ```bash  
   cd Weather-App  
   ```  
3. Install dependencies:  
   ```bash  
   npm install  
   ```  

### Running the App  
1. Start the development server:  
   ```bash  
   npm start  
   ```  
2. Open your browser and go to `http://localhost:3000` to view the app.
